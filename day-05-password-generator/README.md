# DAY 5 — PASSWORD GENERATOR

A simple command-line Password Generator built using Python.

## ABOUT

The program generates a random password based on the length entered by the user.

The password contains lowercase letters, uppercase letters, numbers, and special characters.

The program also validates the user's input, ensures that the minimum password length is 4 characters, generates characters from all four categories, and randomly shuffles the generated password before displaying it.

* `random.shuffle()`
