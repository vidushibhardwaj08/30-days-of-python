# DAY 1 — NUMBER GUESSING GAME

A simple command-line number guessing game built using Python.

##  ABOUT

The computer randomly selects a number between 0 and 100.

The player gets 7 valid guesses to find the number.

After every guess, the program tells the player whether they need to:

- Go higher
- Go lower
- Try again

Invalid inputs do not consume a guess.

## CONCEPTS PRACTICED

- Variables
- User input
- Type conversion
- `if / elif / else`
- `while` loops
- `break`
- `continue`
- `try / except`
- `ValueError`
- `random` module
- f-strings
- `while...else`
