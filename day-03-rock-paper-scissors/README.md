# DAY 3 — ROCK PAPER SCISSORS

A simple command-line Rock Paper Scissors game built using Python.

## ABOUT

The player competes against the computer in a game of Rock Paper Scissors.

The computer randomly selects rock, paper, or scissors, while the player chooses their option from the given choices.

The program determines the winner and displays the choices made by both the player and the computer.

The game also includes input validation and allows the player to play multiple rounds.

## CONCEPTS PRACTICED

* Dictionaries
* `random` module
* `random.choice()`
* User input
* Type conversion
* `if / elif / else`
* `while` loops
* `break`
* `try / except`
* `ValueError`
* `in` operator
* f-strings
* Basic game logic

## HOW TO RUN

Make sure Python is installed, then run:

```bash
python main.py
```
