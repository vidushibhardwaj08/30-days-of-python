# DAY 4 — QUIZ GAME

A simple command-line Quiz Game built using Python.

## ABOUT

The player answers a series of personal-preference-based multiple-choice questions.

The program displays each question along with four possible options, takes the player's answer, checks it against the correct answer, and keeps track of the player's score.

The game currently contains five questions and displays the final score after all questions have been answered.

## CONCEPTS PRACTICED

* Dictionaries

* Lists

* `list()`

* `keys()`

* `values()`

* User input

* String methods

* `.lower()`

* `if / else`

* `while` loops

* Incrementing variables

* Score tracking

* f-strings

* Basic game logic

## HOW TO RUN

Make sure Python is installed, then run:

```bash
python main.py
```
