# DAY 6 — DICE ROLLING SIMULATOR

A simple Dice Rolling Simulator built using Python and Tkinter.

## ABOUT

The program simulates rolling a standard six-sided die.

The user can click the **Roll Dice** button to generate a random number between 1 and 6, and the result is displayed directly in the graphical user interface.

The project uses Tkinter to create the GUI and connects the button to a function that generates and displays the dice result.

## CONCEPTS PRACTICED

* `random` module

* `random.randint()`

* Functions

* Tkinter

* GUI development

* `tk.Tk()`

* `tk.Label()`

* `tk.Button()`

* `.pack()`

* `.config()`

* Button callbacks

* `command`

* `mainloop()`

* f-strings

* Random number generation

## HOW TO RUN

Make sure Python is installed, then run:

```bash
python main.py
```
